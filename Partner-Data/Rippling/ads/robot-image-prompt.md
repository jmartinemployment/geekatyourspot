# Image Prompt: Automation Robot for Rippling Hero

## Purpose
Hero section image for Rippling payroll page. Communicates automation, speed, and payroll processing.

## Visual Description

**Main Subject:** Abstract automation/AI robot icon
- Minimalist, geometric design (not cartoonish or realistic)
- Modern, professional B2B feel
- Line art or flat vector style
- Central figure: robot or interconnected nodes/gears symbol

**Supporting Elements (flowing around the robot):**
- Calculator icon
- Document/form icon
- Checkmark icon
- Clock showing "90 seconds" or just a fast timer symbol
- Flowing arrows or connections between elements
- Payroll-related icons: money, W-2, invoice symbols (optional)

**Color Palette:**
- Primary: Navy (#0B162A)
- Accent: Orange (#C83803)
- Neutral: White, light gray backgrounds
- No bright colors; keep professional/corporate

**Layout:**
- Robot/automation icon centered
- Supporting icons arranged in a circle or flowing pattern around it
- Clean whitespace
- Balanced, symmetrical composition

**Style & Tone:**
- Modern, clean, minimal
- Corporate SaaS aesthetic (think Stripe, Figma, not playful)
- Conveys: speed, efficiency, automation, reliability
- No humans, no faces, no characters
- Tech-forward but approachable

**Dimensions:**
- Design at 1200×600px (can be cropped for hero)
- Works at various widths (responsive)
- Optimize for web (SVG or PNG)
- **TRANSPARENT BACKGROUND REQUIRED** — hero section has its own background color

**Text Overlay:**
Primary overlay: "PAYROLL ON AUTOPILOT" in a starburst design
- Starburst shape: radiating burst rays (12-16 triangular rays) in orange (#C83803) with white fill
- Text: "PAYROLL ON AUTOPILOT" bold, all-caps, white or navy, centered in the starburst
- Position: top-right or top-center of the image, dynamic and eye-catching
- Secondary text (optional): "90 Seconds" smaller, below or inside starburst in supporting position
- Contrast: ensure high legibility; starburst acts as background layer for text

## Inspiration References

**Similar visual styles:**
- Rippling.com product images (their automation illustrations)
- Stripe dashboard icons
- Figma cover images
- Abstract tech/automation icons from Noun Project
- Pricetag's performance dashboard hero (modern, minimal)

## Generation Tools

**Option 1: AI Image Generation**
Use Flux, Ideogram, or DALL-E with the above prompt. Specify:
- "Vector illustration"
- "Modern, minimalist"
- "Corporate SaaS style"
- "Automation theme"

**Option 2: Design Tools (Faster, More Control)**
- Figma (use automation/robot icons from community plugins)
- Canva (search "automation robot" templates, customize colors)
- Adobe Express (template + custom branding)

**Option 3: Hire a Designer**
$500-$1,500 for a custom illustration. Provide this brief + brand colors.

## Deliverables

Final image should be:
- [ ] SVG or high-quality PNG (>1200px wide)
- [ ] Transparent background or clean white background
- [ ] Responsive (works at mobile 375px and desktop 1400px+)
- [ ] Fast loading (<200KB if PNG)
- [ ] Meets WCAG contrast standards for any text overlays
- [ ] Branded with navy and orange color palette

## Usage

Place in hero section of Rippling tool page:
- `/src/app/(site)/tools/accounting/tax-compliance-regulations/ai-payroll-tax/rippling/page.tsx`
- Pass as image prop to `ToolsHeroSection` component
- Alt text: "Rippling automates payroll processing in 90 seconds"
